## 어드민 (lions-admin)

- [ ] **054-SA-SY-05 약관 관리** — 종류 필터(전체 / 서비스 이용약관 / 개인정보 처리방침 / 마케팅 정보 수신 동의)를 알약 버튼에서 탭 스타일로 변경(053 앱 버전 관리와 동일). 우측 상단 "약관 등록" 버튼과 그 팝업 제목을 "약관 관리"로 변경.
- [ ] **039-SA-NC-01 뉴스 클리핑** — 라이온즈 뉴스 선정 방식 변경.
  - 하루 최소 4건. 별도로 선정하지 않아도 긍정 뉴스 상위 4건이 기본 선정되어 그대로 내보낼 수 있음("긍정 상위 4건 자동 선정" 표시).
  - 목록 위에 선정 현황 배너 추가: 선정 건수, 안내 문구, "선정 기사만 보기", "자동 선정으로 되돌리기", "확인하고 앱에 반영". 4건 미만이면 경고(노란색) 표시.
  - 목록 행: 선정된 기사는 파란 테두리·연한 파란 배경, 버튼은 "✓ 선정됨" / "+ 뉴스 선정"(기존 작은 "라이온즈 뉴스 선정" 버튼 대체).
  - 반영 팝업: 4건 미만이면 "앱 라이온즈 뉴스에 반영" 비활성화("N건 더 선정해 주세요").
- [ ] **037-SA-BD-04 이슈 및 팩트** — 등록 모달의 "PUSH 발송"(PUSH 바로 전송 / 전송 안함)을 "발송 채널" 다중 선택(PUSH · 이메일)으로 변경. 둘 다 선택하면 PUSH와 이메일을 모두 발송, 아무것도 선택하지 않으면 발송 안 함. 상단에 한 줄 안내만 두고 버튼에는 아이콘·선택 시 부가 설명 없음. 상세 화면에 "이메일 발송 완료/미발송" 표시 추가. (수정 모달에는 발송 선택 없음 — 기존과 동일)
- [ ] **036-SA-BD-03 PRESS 센터** — 037과 동일하게 등록 모달의 발송을 "발송 채널"(PUSH · 이메일 다중 선택)로 변경, 상세에 "이메일 발송 완료/미발송" 표시.
- [ ] **033-SA-OP-13 구장·인증 설정** — "인증 방식 · 인증 가능 시간" 영역(인증 방식, 경기 시작 몇 시간 전/종료 몇 시간 후, 저장) 삭제(블루 시그널 이벤트 때 감지하므로 경기 시간 설정 불필요). 등록된 구장 목록은 수정만 가능(기존 수정 모달), 우측 상단에 "구장 추가" 버튼 신설 — 모달 입력: 구단·구장·위도·경도·인증 반경(50m 이상). 목록 제목은 "총 N개 구장".
- [ ] **030-SA-OP-10 앰블럼 관리** — 상단에 탭 신설: "미션 앰블럼" / "기념 앰블럼"(탭별로 목록·등록이 분리). 기존 "지급 현황" 목록과 종류 선택 삭제. 기념 앰블럼 더미 5건(받기 상태 표시), 기념 등록 모달에서는 미션 달성 조건 안내 문구 숨김.
  - 회원 상세 모달(앰블럼 탭): "구분"(미션/기념) 열 추가, 우측 상단 "기념 앰블럼 지급" 버튼 추가 — 최고 관리자만 사용 가능, 기념 앰블럼 선택 + 지급 사유(필수) 입력 후 지급, 획득 경로에 "관리자 지급(이름) · 사유" 표시.
- [ ] **029-SA-OP-09 블루 시그널 등록 모달** — 모집 기간 시작/종료를 가로 2열에서 세로 배치(날짜+시간)로 변경. 지급 앰블럼 선택 박스 아래에 "당첨자만 지급" / "등록 인원 전체 지급" 선택 버튼 추가(앰블럼 선택 시 활성, 기본 당첨자만), 상세에도 지급 대상 표시. 등록 모달의 "상태"(예정/진행중/종료)·"활성 설정" 항목 삭제.
- [ ] **028-SA-OP-08 독점 콘텐츠 관리** — 등록·수정 모달의 "상태"(진행/완료) 선택 삭제. 신규 등록은 "진행", 노출 종료 시각이 지나면 자동 "완료".
- [ ] **027-SA-OP-07 상품 관리** — "상품 목록 / 홍보 배너" 구분 탭과 홍보 배너 등록·관리 영역 삭제(홍보 배너는 041 배너 관리에서 관리). 어센틱 샵 / 베리즈 샵 탭만 남김.
- [ ] **022-SA-OP-02 Push 관리 등록 모달** — 알림 종류를 4가지(마케팅 알림 / 구단 알림 / 공지 알림 / 일반 알림)만 선택 가능하도록 변경, 기본값 일반 알림. 나머지 종류(예매 오픈·경기 시작·라인업·결과·이벤트·ZONE·블루 시그널·독점 콘텐츠·선물·직관 기록·미션 등)는 자동 발송이라 앱에서 제어하고 어드민에서는 "자동 발송 목록"에서만 확인. 안내 문구도 변경. 발송 이력 더미의 종류도 4종으로 정리.
- [ ] **022-SA-OP-02 Push 관리 (예약 발송·자동 발송 목록)** — 예약 발송 목록에 "알림 종류" 열 추가, 목록 상단 "총 3건" 옆에 "예약 발송 완료 시 해당 리스트에서 제외되며, 발송 이력 메뉴에서 발송 내역을 확인할 수 있습니다." 안내 추가(더미 3건). 자동 발송 목록의 "구분"(필수/선택) 열 삭제, 자동 발송 상세 모달의 "구분"·"비고" 삭제. 상세 모달에 "제목" 칸을 "내용"과 별도로 추가. 알림 종류명은 앱 설정 항목명과 동일하게 통일("예매·발권·취소·환불 알림").

## 어드민 (lions-admin) — 화면 ID 순서로 정리 (2026.10.14)

> 에디터에 옮기기 전에 새 캡처를 먼저 만드세요(어드민·앱 모두 Actions 수동 실행). 같은 화면의 여러 번 수정은 최종 상태 하나로 합쳤습니다.

### 공통 (모든 화면)
- [ ] **탭 스타일** — 페이지 안 탭을 모두 칩형(회색 바 + 선택 탭 흰색 칩·파란 테두리, 미션 관리 기준)으로 통일. 밑줄형이던 앰블럼 관리(미션/기념), 쿠폰 관리, 앱 버전 관리, 언론사 회원 관리(승인된 회원 14 / 승인 대기 5) 등 포함.
- [ ] **페이징** — 페이지당 건수 기본 10건. 선택은 버튼(20/50/100)이 아니라 드롭다운(10건·20건·30건·50건). 전체가 10건을 넘을 때만 푸터 표시.
- [ ] **등록 버튼 위치** — 모든 화면에서 등록 버튼은 제목 줄 오른쪽 끝. 탭이 있어 제목 아래 별도 줄에 있던 쿠폰 관리·앰블럼 관리·앱 버전 관리의 등록 버튼, 엘도라도 ZONE의 "금칙어 관리·이용 제재 등록"도 제목 줄 오른쪽 끝으로 이동.
- [ ] **경기 선택(경기 일정 가져오기)** — 오늘의 라인업(015)·오늘의 응원단(016)·기록 관리(017)·경기 프리뷰 등록/수정·예매 기간 시작/종료 경기 공통. 드롭다운 삭제 → "경기 정보 박스(경기일·시간·상대팀/구분·경기 상태) + 우측 [날짜 변경] 달력 버튼". 모달을 열면 당일 경기가 자동으로 채워지고, 달력에서 날짜를 누르면 그 날짜의 경기 정보로 변경. 달력은 경기 있는 날만 점 표시·선택 가능(없는 날·이미 등록된 경기·재편성일 미정은 회색), 오늘은 파란 테두리, 월 이동, 같은 날 경기가 둘 이상이면 아래 칩으로 선택. 당일 경기가 이미 등록되어 있으면 "선택할 수 없습니다" 안내와 함께 비워 둠. 예매 기간 시작/종료 경기는 당일 자동 채움 없이 달력만 사용. "경기 일정 관리에서 가져옴" 라벨과 달력 하단 안내 문구는 없음.
- [ ] **경기 상태 명칭** — "경기 후" 유지(경기 종료로 바꾸지 않음. 앱과 동일).

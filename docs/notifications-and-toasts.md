# 예상 알림·토스트 메시지 정리

> 와이어프레임 기준 초안입니다. 문구·발송 시점은 예시이며 확정 시 수정합니다. 앱 안에서는 가이드 페이지(`/case-guide`)의 "알림·토스트" 탭에서도 볼 수 있습니다.

## 1. 예상 알림 (푸시 / 알림 목록)

- **필수**: 설정에서 끌 수 없음, 항상 발송 / **선택**: 설정 항목으로 켜고 끔
- 마케팅 알림은 광고성 정보 수신 동의 회원만, 21시~08시 발송 제외

### 설정 항목 제안

- 직관 기록 리마인드는 별도 알림 종류('직관 기록 리마인드')로 분리 확정

- 굿즈 배송 알림은 굿즈샵을 외부 링크로 운영하므로 제외

## 2. 예상 토스트 메시지

| 상황 | 메시지 |
|---|---|

| 서버 오류 | 일시적인 오류가 발생했어요. 잠시 후 다시 시도해 주세요. |

### 설정

|---|---|

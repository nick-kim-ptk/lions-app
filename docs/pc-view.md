# PC 뷰 규칙 (디자이너·퍼블리셔 참고)

와이어프레임의 PC 뷰는 **1024px부터** 적용되고, 기준 폭은 **1440px**입니다. 모바일 화면의 컴포넌트와 스타일은 그대로 쓰고, 칸 수와 여백만 늘렸습니다. (Tailwind `lg:` = 1024px 이상)

## 구간
| 폭 | 모양 |
|---|---|
| 1024px 이상 | PC 뷰: 상단 메뉴, 콘텐츠 최대 폭 1200px 중앙 정렬, 푸터 |
| 1023px 이하 | 모바일 레이아웃을 가로로 늘림 (하단 탭바 유지). KV는 높이 고정 |

## 상단 메뉴 (GNB)
- 좌측 로고(홈) · 게임 · 티켓+ · 라이온즈 · 소식/안내 · MY, 우측 로그인 정보(이름·멤버십·로그아웃)
- 마우스를 올리면 하위 메뉴가 전체 폭 패널로 열림 (삼성닷컴 방식). 터치 기기는 탭으로 열고 닫음
- MY는 하위 메뉴 없이 MY 화면으로 이동
- 메뉴 항목은 모바일 전체 메뉴와 같은 데이터(`src/data/allMenu.ts`)를 사용. 라운지는 PC 메뉴에서 제외

## PC에서 제공하지 않는 것
| 항목 | 처리 |
|---|---|
| 알림, 햄버거(전체 메뉴) | 숨김 |
| 라운지 | 메뉴에서 제외 |
| 홈 경기 카드의 좌석 정보·스마트 티켓 | 숨김 |
| 예매 내역의 스마트 티켓 발권 영역, 선물 내역의 스마트 티켓 버튼 | 숨김 |
| 티켓 선물하기 버튼 | "모바일 앱에서 이용해 주세요" 안내 |
| 티켓 예매하기 버튼 | 티켓링크(더미 주소)를 새 창으로 열기 |

## 레이아웃 규칙
- 전체 폭 배경이 필요한 KV는 `pc-bleed`, 그 안의 글자·그래픽은 `pc-kv-pad` / `pc-kv-left` / `pc-kv-right`로 1200px 컨테이너에 맞춤 (`src/index.css`)
- KV는 높이를 고정하고 폭만 늘림 (이미지는 가운데 기준으로 잘림)
- 비율(`aspect-`)로 높이가 정해지는 요소는 PC에서 비율을 바꾸거나 높이를 고정 (예: MY 멤버십 카드 16:10)
- PC로 배치를 바꾼 화면: 홈(뉴스 2열), 경기 일정(달력+목록 2단), 티켓+(경기 2열), MY(카드 가로형), 선수단 소개(5열). 나머지 화면은 1200px 컨테이너에 그대로 배치

## 코드 위치
`components/PcGnb.tsx`(상단 메뉴·푸터) · `components/Layout.tsx`(틀) · `components/AppOnlyNotice.tsx`(앱 이용 안내) · `utils/pc.ts`(PC 판별, 예매 새 창) · `data/allMenu.ts`(메뉴 데이터)
